This repository contains structured Python exercises and projects covering core foundational programming concepts up to Object-Oriented Programming (OOP). Each directory corresponds to a specific topic with standalone scripts solving individual problem statements.

## 🚀 How to Run

1. Verify Python 3.x is installed:
   ```bash
   python --version
   ```
2. Navigate to the `SKYTUS` directory:
   ```bash
   cd SKYTUS
   ```
3. Run any target script:
   ```bash
   python "Python/OOP Basics/Bank_Account.py"
   ```
